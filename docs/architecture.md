# معماری

## تصمیم چندمستأجری

گزینه‌ها:

| گزینه | مزیت | هزینه |
| --- | --- | --- |
| دیتابیس جدا برای هر شرکت | ایزوله‌سازی قوی | مهاجرت، بکاپ و اتصال پیچیده برای فاز ۱ |
| اسکیما جدا | میانه | پشتیبانی SQLite تست و عملیات سخت‌تر |
| دیتابیس مشترک + `company_id` | ساده‌ترین مسیر قابل نگهداری و آمادهٔ SaaS | ایزوله باید در اپلیکیشن سخت‌گیرانه باشد |

انتخاب فاز ۱: **دیتابیس مشترک، `company_id`، Global Scope بسته‌شونده، و middleware تعیین tenant.**

اگر context شرکت نباشد، کوئری مدل‌های tenant هیچ ردیفی برنمی‌گرداند. این رفتار عمدی است: نبود tenant نباید به نمایش همهٔ داده‌ها منجر شود.

روی درخواست احراز هویت‌شده، scope شرکت را از `company_id` توکن می‌خواند، نه از یک context باقی‌مانده. به این شکل حتی اگر ترتیب middleware در worker طولانی‌عمر جابه‌جا شود، دادهٔ شرکت دیگر لو نمی‌رود.

`TenantContext` نقطهٔ تعویض آینده است. اگر بعداً دیتابیس جدا لازم شود، resolver عوض می‌شود نه کنترلرها.

جداسازی فقط با مخفی کردن دکمه نیست. هر مسیر API یا permission middleware دارد یا policy، و binding مدل با scope شرکت انجام می‌شود.

## احراز هویت

- Laravel Sanctum، فقط Bearer token. fallback به session وب خاموش است تا بستن نشست با حذف توکن دور زده نشود.
- توکن به یک شرکت گره خورده است (`personal_access_tokens.company_id`).
- اگر کاربر چند شرکت داشته باشد، تا انتخاب شرکت توکن صادر نمی‌شود.
- ادمین پلتفرم می‌تواند بدون عضویت وارد context یک شرکت شود، فقط با هدر `X-Company-Id` یا انتخاب صریح. این دسترسی در activity log قابل ثبت است.
- رمز با cast `hashed` لاراول ذخیره می‌شود.
- بازیابی رمز ایمیل را افشا نمی‌کند.
- ستون‌های 2FA روی `users` رزرو شده‌اند. خود 2FA در فاز ۱ فعال نیست تا امنیت نمایشی فروخته نشود.

## RBAC

مجوزها کاتالوگ سراسری‌اند. نقش‌ها برای هر شرکت ساخته می‌شوند و قابل ویرایش‌اند. مجوز مستقیم (`user_permissions`) مستقل از نقش است.

کاربر نمی‌تواند مجوزی را بدهد که خودش ندارد، مگر مالک، مدیرعامل یا ادمین پلتفرم. نقش `company-owner` همیشه مجموعهٔ کامل مجوزهای شرکت را نگه می‌دارد تا شرکت قفل نشود.

## ماژولار بودن

منطق در `app/Modules` و زیرساخت مشترک در `app/Core` است. Controller نازک است. ساخت شرکت، عضویت، دعوت و صدور توکن Action هستند.

Feature flag برای ماژول‌های بعدی از روز اول وجود دارد و پیش‌فرض خاموش است. `foundation` قفل است.

## زمان

ذخیره در UTC. نمایش با timezone شرکت، پیش‌فرض `Asia/Tehran`. ساعت کاری شنبه تا پنجشنبه، جمعه تعطیل، ۰۹ تا ۱۷، ۶۰ دقیقه استراحت، ۱۵ دقیقه فرجه. قابل ویرایش برای هر شرکت.

## API

نسخه: `/api/v1`. قرارداد:

```json
{ "success": true, "data": {}, "message": null, "errors": [] }
```

خطای اعتبارسنجی `errors` را به شکل map فیلدها برمی‌گرداند تا فرم بتواند همان فیلد را نشان دهد.

## چرا Inertia نه؟

API باید از وب مستقل باشد تا Android و iOS بعداً همان قرارداد را مصرف کنند. فرانت Vue جدا است و فقط از `/api/v1` حرف می‌زند.
