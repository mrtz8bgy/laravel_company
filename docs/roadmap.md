# نقشه راه

فاز ۱ تمام شده: احراز هویت، شرکت، واحد، تیم، نقش، مجوز، ساعت کاری، دعوت، داشبورد پایه، Docker و تست ایزوله‌سازی.

فاز ۲ تمام شده: حضور، وضعیت کاری، چک‌این صبح، گزارش روزانه، محاسبهٔ تأخیر از ساعت کاری، و جای خالی وظیفهٔ امروز.

فاز ۳ تا ۱۳ تمام شده: پروژه، منابع انسانی، پیام، تقویم، فروش، بازاریابی، مالی، پشتیبانی، تأیید، اسناد و سنجه. دادهٔ نمونه در seeder است.

هر فاز باید همین چرخه را طی کند: بررسی کد موجود، طراحی، پیاده‌سازی، تست، بازبینی امنیت، مستند، commit. کد تکراری و God class پذیرفته نیست.
